Infrastructure as code

A path from first container to production

Follow the order. Each step builds on the one before.

  1. DockerContainerize a small app and push it to a registry.
  2. AWS or AzureLearn networking, identity and compute in your own account.
  3. TerraformRebuild that environment from code, then destroy and recreate it.
  4. KubernetesRun your app on a cluster with scaling and rolling updates.
  5. GitHub Actions or JenkinsBuild, test and publish your image on every commit.
  6. Argo CDLet Git changes deploy to the cluster automatically.
